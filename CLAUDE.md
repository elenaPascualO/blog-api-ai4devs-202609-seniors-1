# blog-api

## Regla del repositorio

Este repositorio es el dueño del contenido. Todo archivo nuevo debe empezar con un comentario que lo indique, por ejemplo:

```ts
// blog-api: este repositorio es el dueño del contenido.
```

Usa la sintaxis de comentario propia del tipo de archivo (`//`, `#`, `<!-- -->`, etc.), en la primera línea.
